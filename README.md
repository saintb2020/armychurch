# ARMY CHURCH 公式サイト｜納品データ

中目黒のインターナショナル教会 ARMY CHURCH の公式サイト一式です。
外部フレームワーク・ビルド作業は不要で、**ファイルをサーバーに置くだけで動きます。**

---

## 1. ファイル構成

```
index.html          サイト本体（HTML / CSS / JavaScript をすべて内包）
robots.txt          検索エンジン向け設定
sitemap.xml         サイトマップ
assets/             画像・動画・アイコン（36ファイル）
```

合計約 5MB。データベースやサーバーサイドの処理は使っていません。

---

## 2. 公開手順

`index.html`・`robots.txt`・`sitemap.xml`・`assets/` フォルダを、
**同じ階層のまま**公開ディレクトリ（例: `public_html/`）へアップロードしてください。

```
public_html/
├── index.html
├── robots.txt
├── sitemap.xml
└── assets/
```

`https://armychurch.jp/` でトップページが表示されれば完了です。

### 公開ドメインが armychurch.jp 以外の場合

以下の4か所のURLを実際のドメインに書き換えてください。

| ファイル | 箇所 |
|---|---|
| `index.html` | `og:image` / `og:url`（10〜12行目付近） |
| `index.html` | `<link rel="canonical">` |
| `index.html` | 構造化データ（JSON-LD）内の `url` / `image` / `logo` |
| `sitemap.xml` `robots.txt` | `https://armychurch.jp/` の記述 |

## 3. 公開後にお願いしたいこと（SEO）

サイト側のSEO対策（タイトル・説明文・構造化データ・サイトマップ・
画像の代替テキスト）は実装済みです。公開後は以下をお願いします。

1. **Google Search Console にサイトを登録**し、`sitemap.xml` を送信
   （インデックス登録が早まります）
2. **Googleビジネスプロフィールに補助カテゴリを追加**
   すでに登録・オーナー確認済みですので、メインカテゴリ「教会」に加えて
   「キリスト教教会」「プロテスタント教会」を追加してください。
   数分で終わり、リスクなく検索対象が広がります。
3. **クチコミを増やす**（現在4件 → まずは20件）
   地図検索の表示順に最も効きます。日曜の参加者に依頼するのが現実的です。

### 検索順位についての補足

「中目黒 教会」は地図検索が優先される検索語です。現在の上位は
「中目黒教会」という**名前そのものが検索語と一致している**教会が占めており、
プロフィールの運用品質ではARMY CHURCH側が上回っています。
そのため、この検索語だけを追うより、競合がほぼ対策していない

- 「中目黒 教会 英語」
- 「東京 バイリンガル 教会」
- 「中目黒 インターナショナルチャーチ」

を先に取りにいくほうが成果が出やすい状況です。
これらは英語対応を打ち出している本サイトと相性が良く、
公開すること自体が対策になります。

## 4. よくある更新のしかた

すべて `index.html` をテキストエディタで開いて編集します。

### 文章を変える
該当の日本語をそのまま検索して書き換えてください。
英語の併記文はすぐ下の行にあります。

### 日曜の予定・住所を変える
`予約なしで、ふらっとどうぞ。` のセクション（ページ下部）にまとまっています。
あわせて以下も直してください。
- ページ最上部の構造化データ内 `openingHoursSpecification`（現在は日曜 9:30〜13:00）
- ファーストビューの赤いラベル `毎週日曜 10:00`

### 写真を差し替える
`assets/` 内の同名ファイルを差し替えると反映されます。
推奨サイズは以下のとおりです。

| 用途 | ファイル名 | 推奨サイズ |
|---|---|---|
| トップの背景動画 | `inside.mp4` | 1920×1080・20秒程度・5MB以内 |
| スライドショー | `gallery-*.jpg` | 横960px程度 |
| 牧師紹介 | `pastors.jpg` | 横1400px程度 |
| SNSシェア画像 | `ogp.jpg` | 1200×630 |

### スライドショーに写真を追加する場合（注意）
写真は**前半・後半でまったく同じ並び**にしてください（現在は7枚×2セット）。
これが崩れると、ループのつなぎ目で画像が飛びます。

さらに、CSS内の `--dist` の値も更新が必要です。

```
.gallery-track { --dist: 3486px; }              /* PC:  7枚 × (480px + 余白18px) */
@media(max-width:700px){ --dist: 2226px; }      /* スマホ: 7枚 × (300px + 余白18px) */
```

例）8枚に増やす場合は `8 × 498 = 3984px` / `8 × 318 = 2544px` になります。

### スライドの速度を変える
同じく `index.html` のCSS内、`animation: scroll 40s`（PC）と
`animation-duration: 26s`（スマホ）の秒数を変えてください。
**数字を大きくすると遅く**なります。

## 6. AI（Claude・ChatGPTなど）で修正する場合

このサイトは **`index.html` の1ファイルだけで完結**しているため、
AIに修正を頼むのに向いています。専門知識がなくても更新できます。

### 基本の流れ

1. `index.html` をAIに**添付**する
2. 直したい内容を日本語で伝える
3. 返ってきた `index.html` を、サーバー上のファイルに**上書き**する

### 依頼のしかたの例

> 添付のindex.htmlを修正してください。
> 日曜の開始時間を10:00から10:30に変えたいです。
> 日本語・英語の両方と、ページ上部の構造化データも忘れずに直してください。

> 「よくある質問」に「駐車場はありますか？」という項目を、
> 既存の質問と同じ書き方（日本語＋英語の併記）で追加してください。

### 頼むときの注意点

- **`assets/` フォルダのファイル名は変えない**でください。
  画像を差し替えるときは「同じ名前で上書き」が安全です。
- **スライドショーの写真を増減した場合**は、CSS内の `--dist` の値も
  変更が必要です（計算式は「4. よくある更新のしかた」に記載）。
  AIに頼む際は「--distの値も合わせて更新して」と伝えてください。
- 修正後は、**スマホ表示**も必ず確認してください
  （パソコンのブラウザで画面幅を狭めるだけでも確認できます）。
- 大きく作り変える依頼より、**1回に1か所ずつ**頼むほうが確実です。

### 元に戻したいとき

修正前の `index.html` をコピーして残しておけば、いつでも戻せます。
（例: `index_backup.html` として保存しておく）

## 7. 技術的な補足

- 外部読み込みはGoogle Fonts（Anton / Caveat / Noto Sans JP）のみ
- 画像は WebP と JPEG を用途別に使い分け、スマホには軽い画像を自動配信
- 動画はスマホの通信量に配慮し20秒に編集済み
- ダークモード非対応（意図的に固定配色）
- JavaScriptはごく少量（ヘッダーの背景切替・スクロール時のフェード表示・
  FAQの開閉）。スライドの動きはCSSのみで実装しています
